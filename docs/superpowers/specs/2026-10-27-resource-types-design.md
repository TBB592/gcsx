# 资料类型扩展

用户已确认加入此前建议的分类，后续自行提供资料。保持现有视觉风格与静态托管，一级分类为全部资料、课程学习、选课指引、校园生活；课程学习中提供文科、理科子类。手机采用可换行的横向按钮，电脑保留侧边栏。

课程资料保持现有链接，新类型暂不制造占位资料，显示带内容说明的整理中状态。搜索与当前分类同时生效；文科理科快捷入口自动展开课程子类。新资料配置通过 type 指定 courses、course-guide 或 campus-life；已有资料缺省为 courses，课程必须提供 science 或 humanities，其他类型不要求 area。资料的标题、分类、简介和类型名称都纳入本地搜索。

验证手机和电脑的一级/二级分类、空状态、搜索叠加及原阅读链接；通过后发布到原网址。
