# 学习资料库搜索增量设计

在现有首页资料列表上方加入与紫色主题一致的搜索框，保留校园照片、现有分类、阅读页面和所有资料链接。

## 选择

推荐使用浏览器本地即时筛选：输入后立即展示匹配资料，无需后端或额外服务。相比单独的搜索结果页，操作更直接且无需重复维护页面；相比搜索 PDF 正文，不需要下载、解析整份文件，手机访问更轻便。

## 搜索行为

- 输入框标签为“搜索学习资料”，提示“搜索学科、资料名称或关键词”。
- 匹配资料标题、学科分类和简介；忽略首尾空格及英文大小写，多个空白分隔的关键词须全部匹配。
- 搜索与当前文科/理科分类共同生效，切换分类保留关键词。
- 显示匹配数量；无结果时显示“没有找到相关资料”，提示尝试其他关键词或分类。
- 提供清空按钮，清空关键词后恢复当前分类资料；输入为空时沿用原分类空状态。
- 搜索内容不写入 HTML，不记录、不上传访客输入。
- 新增学科通过现有生成流程自动纳入搜索，不维护第二份搜索目录。
- 禁用 JavaScript 时隐藏搜索控件，继续展示全部资料供直接阅读。

## 实现范围

仅调整首页资料模板、资料卡片搜索字段、library.js 和配套样式，重新生成首页。保持静态托管、阅读页、页码跳转、QQ群反馈和计数地址。

## 验证

在手机和电脑宽度验证标题搜索、简介关键词、多词搜索、空格处理、分类叠加、清空及无结果状态；确认特殊字符输入安全、无横向溢出，原阅读入口和无 JavaScript 回退可用。验证通过后更新原 GitHub Pages 网址。
